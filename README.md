# Mines CLI source snapshot

This repository preserves the initial shared Mines source snapshot used to prepare the standalone command-line host. It remains available for source provenance and historical comparison.

**Current development belongs in the [shared Mines monorepo](https://github.com/mines-harness/macos).** The host, provider adapters, web client, contracts, and desktop app are maintained together there. Do not treat this snapshot's `main` branch as the latest released host.

- [Current source and documentation](https://github.com/mines-harness/macos)
- [Unified desktop and CLI releases](https://github.com/mines-harness/macos/releases)
- [Earlier standalone CLI downloads and checksums](https://github.com/mines-harness/cli/releases)
- [Windows](https://github.com/mines-harness/windows)
- [Android](https://github.com/mines-harness/android) · [iOS](https://github.com/mines-harness/ios)

Mines builds on [T3 Code](https://github.com/pingdotgg/t3code). The original [MIT license](LICENSE) and third-party notices remain in this snapshot. Mines is independently maintained.
